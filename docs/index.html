// 01 Join

One code.
Any distance.

The host clicks Start Hosting and shares an SC-… code. Friends paste it. Same Wi-Fi or the other side of the country, it just connects. No VPN, no port forwarding.

  • DirectPC to PC whenever possible, punching through home routers (powered by iroh).
  • FallbackIf a direct link can't be made, an encrypted relay forwards data it can't read. Files are never stored anywhere.
  • LANOn the same network the fast local connection is used automatically, and Scan for Hosts finds the host with no internet at all. Reconnecting is one click.

TIPAnyone with your code can join. Posting it publicly? Turn on Use PIN.

// 06 FAQ

Before
you ask.

More in the README.

Does it work at a LAN party with no internet?

Yes. On a local network SyncCrate finds hosts with mDNS and UDP broadcast and syncs PC to PC at 100–900 MB/s, no internet connection needed. Friends pick the host under Scan for Hosts, or use Connect by IP. Join codes are for connecting over the internet.

If a PC can't see the host, it's almost always Windows Firewall: see the next answer.

How many friends can sync from one host?

There's no fixed limit. Each friend syncs from the host independently, whenever they're ready, so people can join halfway through the evening.

The host's upload is the bottleneck: friends syncing at the same time share it. For a big LAN party, sync in waves or have people sync before they arrive.

My friend can't connect

It's almost always Windows Firewall. On the host PC click Fix Windows Firewall (shown while hosting and in Network Check), then use Test in Network Check. SyncCrate uses TCP port 9847 for sessions and UDP port 47625 for discovery.

Does it work over the internet?

Yes. Paste the host's join code, nothing else needed. SyncCrate connects directly between PCs when it can, and falls back to an encrypted relay when it can't. The relay only forwards data it can't read; your files are never stored anywhere.

Anyone with your code can join, so turn on Use PIN if you post it publicly. Tailscale or ZeroTier also still work with Connect by IP.

Will it break my mods?

Nothing changes until you approve the sync plan, and existing files are only replaced when you choose to. Every file is hash-verified, risky scripts are flagged, and backups let you roll back. Only sync with people you trust, and make sure everyone runs the same SyncCrate version.

Do I need admin rights?

No. The only exception is a game folder Windows protects, like ReShade/GShade under Program Files. SyncCrate tells you and offers to restart as administrator.

Is there a file size limit?

Up to 2 GB per file, no limit on total size.

macOS says the app is "damaged"

The app isn't notarized yet. Run xattr -cr /Applications/SyncCrate.app once, then open it normally.
