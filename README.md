One friend hosts. Everyone else gets an exact copy of their mods and saves, straight from PC to PC. Free, open source, no accounts, no cloud.

## Play together

Your friend pastes a join code and gets your exact mods, saves and configs. Nobody's stuck on "version mismatch" in the lobby. You see every change before it happens, and you can undo it.

<img src="assets/gifs/play-together.gif" width="100%" alt="A friend pastes the join code, clicks Sync Now and gets the host's 12 mods" />

## Share your setup

Send a link to your exact setup. Friends see what they're missing and get it from you. Mods that have to come from their creator (Patreon, "no reupload") arrive as the creator's link instead.

<img src="assets/gifs/share-setup.gif" width="100%" alt="Opening a friend's pack link shows which mods you have, are missing or have a different version of" />

## Keep it synced

New mods reach everyone automatically. At a LAN party it works without internet. Backups, file history and one-click undo mean a sync never breaks your game.

<img src="assets/gifs/keep-synced.gif" width="100%" alt="Turning on Stay in sync pulls the host's six new mods automatically" />

**Works with the games you already mod:** The Sims 4, Minecraft, Valheim, Stardew Valley, World of Warcraft, Lethal Company, Terraria and [122 more](GAMES.md).

## Get started

1. **Download** SyncCrate for Windows, macOS or Linux from [Releases](../../releases/latest) and install it on every PC.
2. **One friend clicks Start Hosting.** SyncCrate finds the game folder by itself.
3. **Everyone else joins:** pick the host under **Scan for Hosts** (same network) or paste the join code (anywhere).
4. **Click Compare & Sync**, check the plan, then **Sync Now**.

> [!NOTE]
> SyncCrate isn't code-signed yet, so the first launch shows a warning.
> **Windows:** "Windows protected your PC" → **More info** → **Run anyway**.
> **macOS:** System Settings → Privacy & Security → **Open Anyway**. If it says "damaged", run `xattr -cr /Applications/SyncCrate.app` once.

Can't connect? Click **Fix Windows Firewall** on the host PC. More help in the [FAQ](FAQ.md).
